# LightRef 1.0.0

Consulte README.md e PUBLICACAO.md na raiz do repositório para desenvolvimento, instalação e publicação.

Este plugin substitui o LightRef anterior: IDs com.lightref / com.lightref.panel, pasta de extensão com.lightref.cep e dados em %APPDATA%\LightRef.

Arraste a divisória acima das abas para ajustar o espaço dos menus. Duplo clique restaura 70/30. Materiais ficam em Material; HDR e cores do cenário em Ambiente.
